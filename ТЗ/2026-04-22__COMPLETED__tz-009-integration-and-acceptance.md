# TZ-009 Интеграция и приемка MVP

## Status
COMPLETED

## Goal
Провести сквозную интеграцию и зафиксировать критерии готовности MVP.

## Business context
Перед передачей в эксплуатацию нужно подтвердить корректность полного бизнес-сценария.

## System context
Проверяется end-to-end поток: ввод -> totals -> export.

## Functional requirements
- Выполнить сквозной сценарий:
  - ввод данных через универсальную строку (раздел -> автоопределение формы);
  - расчет агрегатов 4/5/6;
  - экспорт `.xlsx`.
- Проверить перенос общего блока полей во все нужные формы.
- Проверить сценарии количества строк: 0, 1, N.
- Проверить контракт API endpoint'ов из `API_SPEC.md` (документ, entries, totals, export, dictionaries).
- Проверить корректность фильтров списка строк и статусов валидации.
- Зафиксировать протокол приемки и найденные дефекты.

## Non-functional requirements
- Повторяемость сценариев приемки.
- Понятные чек-листы для повторной проверки.

## Acceptance criteria
- Все критичные сценарии пройдены.
- Экспорт корректен и совместим с шаблоном.
- Критические дефекты отсутствуют.
- Подтверждено, что экспорт использует те же данные, что и последний успешный preview.

## Edge cases
- Неполные данные и возврат пользователю валидируемых ошибок.
- Повторный экспорт после исправления ошибок исходных строк и повторного пересчета.

## Dependencies and risks
- Зависит от TZ-002..TZ-008.

## Open questions
- Кто утверждает финальный чек-лист приемки и критерий релиза?
