# TZ-001 Анализ Excel и mapping-spec

## Status
COMPLETED

## Goal
Подготовить формальную спецификацию маппинга данных для форм 4, 5 и 6 на основе исходного шаблона `.xlsx`.

## Business context
Для ускорения заполнения форм нужна детерминированная схема переноса и вычисления данных для форм 4/5/6.

## System context
Артефакт используется backend/frontend командами как единый источник истины перед разработкой CRUD, расчетов итогов и экспорта для форм 4/5/6.

## Functional requirements
- Проанализировать листы шаблона для форм 4, 5, 6.
- Описать маппинг `сущность -> форма -> лист -> ячейка/диапазон`.
- Выделить общий блок полей: наименование/шифр, этап, отчетный год, планируемый год.
- Описать табличные блоки форм 4/5/6 и правила добавления строк.
- Описать правила расчета итогов по формам 4/5/6.

## Non-functional requirements
- Документ в Markdown.
- Формулировки однозначные и проверяемые.
- Термины единообразные во всех разделах.

## Acceptance criteria
- Есть отдельный документ `mapping-spec` с полной таблицей маппинга для форм 4/5/6.
- Для каждого поля указан источник и целевая ячейка/диапазон.
- Для каждого расчетного поля указано правило вычисления.

## Edge cases
- Отсутствие части входных строк в формах 4/5/6.
- Пустые ячейки в шаблоне или объединенные диапазоны.
- Различия в названиях листов (варианты с суффиксами).

## Dependencies and risks
- Зависит от финального утверждения структуры Excel-шаблона.
- Риск неоднозначного соответствия некоторых полей.
