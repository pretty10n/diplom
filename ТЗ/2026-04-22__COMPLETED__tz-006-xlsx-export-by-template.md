# TZ-006 Экспорт в .xlsx по шаблону

## Status
COMPLETED

## Goal
Реализовать экспорт итогового пакета форм в `.xlsx` на базе исходного шаблона.

## Business context
Пользователь должен получать файл в формате, совместимом с регламентной формой.

## System context
Сервис `XlsxExportService` на backend, работающий со структурой шаблона.

## Functional requirements
- Загружать и использовать предоставленный `.xlsx` как шаблон.
- Заполнять в шаблоне только формы 4, 5, 6.
- Корректно обрабатывать многократные строки форм 4/5/6.
- Возвращать сформированный файл для скачивания через endpoint `POST /api/v1/documents/{documentId}/export`.
- Поддержать только режим `mode=fill_template` для MVP.
- При несоответствии шаблона ожидаемой структуре возвращать `VALIDATION_ERROR` с деталями проблемных листов/ячеек.

## Non-functional requirements
- Не ломать форматирование и структуру шаблона: стили, объединения, размеры, формулы, печатные настройки, скрытые листы, именованные диапазоны.
- Генерация файла до 5 секунд для стандартного сценария.
- Backend изменяет только заранее определенные целевые ячейки.

## Acceptance criteria
- Выгруженный файл открывается в Excel без ошибок.
- Ключевые поля и строки совпадают с preview в системе.
- Структура листов соответствует шаблону.
- Визуальный макет исходного файла сохраняется полностью.

## Edge cases
- Пустые формы-источники.
- Длинные текстовые поля в «первичных документах».

## Dependencies and risks
- Зависит от TZ-001, TZ-004, TZ-005.
