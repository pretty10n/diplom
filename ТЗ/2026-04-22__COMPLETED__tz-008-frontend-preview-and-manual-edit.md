# TZ-008 Frontend предпросмотр и проверка

## Status
COMPLETED

## Goal
Реализовать экран проверки агрегатов форм 4/5/6 и сценарий проверки перед экспортом.

## Business context
Пользователь должен проверить агрегаты и исправить исходные строки при обнаружении ошибок до экспорта.

## System context
Экран получает данные из `GET /totals`, отображает ошибки и навигацию к проблемным строкам.

## Functional requirements
- Показать агрегаты форм 4/5/6 и список ошибок валидации.
- Реализовать переход от ошибки к строке на экране универсального ввода.
- Добавить кнопку «Сформировать Excel».

## Non-functional requirements
- Ясные индикаторы статуса автозаполнения и ошибок.
- Предпросмотр должен соответствовать данным, которые будут записаны в Excel при ближайшем экспорте.

## Acceptance criteria
- Пользователь видит агрегаты форм 4/5/6.
- Пользователь видит список ошибок и может перейти к соответствующим строкам для исправления.
- После исправления строк агрегаты обновляются и используются для экспорта.

## Edge cases
- Пустой preview при отсутствии строк ввода.
- Ошибки пересчета по отдельным разделам при частично валидных данных.

## Dependencies and risks
- Зависит от TZ-006, TZ-007.
