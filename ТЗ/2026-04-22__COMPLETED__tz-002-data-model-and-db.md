# TZ-002 База данных и доменная модель

## Status
COMPLETED

## Goal
Спроектировать и реализовать доменную модель и структуру БД для хранения документа, общего блока и универсальных строк ввода для форм 4/5/6.

## Business context
Система должна сохранять введенные данные и использовать их для автозаполнения зависимых форм.

## System context
Backend на Java/Spring/Postgres. Модель должна поддерживать переменное количество строк и определение формы/раздела по `sectionKey`.

## Functional requirements
- Создать сущности: `document`, `document_common_info`, `document_entry`, `document_totals_snapshot` (или эквивалентные по смыслу).
- Связать сущности через единый `document.id` (UUID).
- Для `document_entry` хранить:
  - `section_key` (обязательный, определяет `form_no` и `section_no`);
  - `row_no` (назначается сервером);
  - `fields` (JSONB с пользовательскими колонками);
  - `computed` (JSONB с расчетными колонками для 4/5/6: `col11`, `col12`);
  - `validation_status`.
- Хранить справочники для выпадающих значений (`sectionKeys`, `col13_2Values`, `col5_2Values`) в таблицах или конфигурации с версионированием.
- Добавить ограничения:
  - `report_year` и `plan_year` — 4-значные годы;
  - `section_key` только из допустимого словаря;
  - `supplier_inn` в валидируемом формате.
- Обеспечить уникальность и стабильную перенумерацию `row_no` в рамках (`document_id`, `section_key`) после удаления строки.

## Non-functional requirements
- Миграции совместимы с Postgres 15+.
- Именование таблиц/полей консистентное.
- Поля JSONB индексируются для типовых фильтров списка строк (`sectionKey`, `validationStatus`, `formNo`).

## Acceptance criteria
- Миграции применяются без ошибок.
- Можно создать документ и добавить в него универсальные строки для каждой формы 4/5/6 через `sectionKey`.
- Сущности корректно читаются через JPA/ORM слой.
- После удаления строки выполняется корректная перенумерация `row_no`.

## Edge cases
- Нулевое количество строк в одной из форм.
- Большое количество строк (N >> 100).
- Несогласованность `sectionKey` и переданных полей `fields`.
