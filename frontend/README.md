# Frontend TZ-007 / TZ-008

Реализация шага мастера ввода и CRUD-интеграции для форм 4/5/6.

## Что реализовано

- Шаг 1: ввод и сохранение общих данных документа.
- Шаг 2: универсальная строка с автоматическим определением формы по разделу.
- Таблица введенных строк с фильтрами по разделу, форме и статусу.
- Действия по строкам: добавить, редактировать, дублировать, удалить.
- Интеграция со справочниками и CRUD API (`/api/v1`).
- UX-состояния: загрузка, пусто, ошибки, подтверждение удаления, уведомления об успехе, несохраненные изменения.
- Шаг 3: предпросмотр агрегатов (формы 4/5/6), список ошибок и переход к проблемной строке.
- Экспорт: кнопка «Сформировать Excel» с вызовом `POST /api/v1/documents/{id}/export`.

## Запуск

Требуется Node.js 20+.

```bash
npm install
npm run dev
```

По умолчанию Vite проксирует `/api` на `http://localhost:8080`.
